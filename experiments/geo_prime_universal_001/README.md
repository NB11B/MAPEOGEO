# GEO-PRIME-UNIVERSAL-001 — Cyclic geometric primality

## Formal mathematical criterion
Let the orbit O(n,k) be the subgroup generated by step k in the additive cyclic group Z/nZ. Then for n>=2:

`Nat.Prime n ↔ ∀k, 1<=k<n → |O(n,k)|=n`.

Equivalently, every nonzero residue is a generator of the additive cyclic group. This is an established characterization of prime order cyclic groups. The orbit length is n/gcd(n,k). A composite n has a nontrivial gcd witness. A prime n has none.

A second independent characterization is `n | binomial(n,k)` for every 0<k<n. This is an established theorem, not a new discovery.

## Implemented experiment
- Python standard library only, exact modular arithmetic and exact binomial coefficients.
- Checked all n=1..300 vs independent trial-division oracle.
- Eight local tests passed; 62 primes and zero disagreements in either criterion.
- Concrete witness n=9, step k=3, orbit 0→3→6→0; 9 is composite.
- This uses O(n²) or greater repeated arithmetic, not an improved prime test.

## Qualification boundaries
The current experiment is **not** a new prime generator, efficient primality algorithm, or independent proof of a previously unknown theorem. It does not certify unrestricted MAPEOGEO operator discovery. The cyclic criterion remains to be formalized in Lean against `Nat.Prime` with the group's orbit size proved as n/gcd(n,k). Finite tests do not substitute for that proof.
