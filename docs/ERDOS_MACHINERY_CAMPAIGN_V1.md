# Erdős Machinery Campaign v1

Purpose: falsify the claim that the current MAPEOGEO/PSMSL work machinery can
generalize to a broad frontier of unsolved mathematics.

The campaign never interprets capability overlap as a proof.  It has two gates:

1. corpus triage from the frozen teorth/erdosproblems metadata;
2. statement-level inspection before any executable mathematical route is
   authorized.

Frozen unresolved policy:
`open`, `open (Lean)`, `verifiable`, `falsifiable`, `decidable`.

The first observed source snapshot contained 633 such entries.  A contemporaneous
third-party live tracker reported 635 remaining, so source drift is explicitly
recorded rather than reconciled by assumption.

Current executable-family overlap is intentionally coarse: graph, geometry, and
analysis tags trigger statement inspection; number-theory/combinatorics-only
rows expose an implementation/certification deficit.

No open Erdős problem is marked solved by this campaign.
