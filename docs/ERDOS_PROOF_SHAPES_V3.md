# Erdős Proof-Shape Layer v3

This layer classifies formal theorem signatures by top-level logical/work shape,
not by mathematical subject.

Recognized features include universal/existential quantifiers, mixed quantifier
order, eventual/filter statements, asymptotic Big-O/Little-o forms,
equivalences, implications, extrema, and cardinality.

The classifier is deliberately conservative and syntax-level.  It does not
claim logical equivalence after elaboration and does not prove any theorem.
Its purpose is to route proof obligations toward the correct missing machinery.

Qualification fixtures cover formal shapes represented by Erdős Problems
19, 23, 60, and 89.
